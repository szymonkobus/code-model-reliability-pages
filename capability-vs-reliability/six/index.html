About this view

Each panel is the crossings page's plane for one set: D99 (vertical) against D50 (horizontal) — the difficulties at which a model's failure rate crosses 1% and 50% — on that set's own difficulty axis with equal logit scales and the y = x line. A model's crossing beyond the set's easiest or hardest task is an open mark at the edge pointing the way it lies. A model is a point in a panel only where it has a fit on that set; the count in each panel's corner is the number of points drawn. The single-set view with its level controls is at /capability-vs-reliability/.
